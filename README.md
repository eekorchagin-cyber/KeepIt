# KeepIt

Учёт домашних вещей и расходников. Пока — **локальный прототип** на одном устройстве (PWA / браузер).

Семью и синхронизацию через Supabase подключим после отработки мест, вещей, QR и печати.

## Запуск

```bash
npm install
npm run dev
```

- Компьютер: http://localhost:5174/
- Телефон в той же Wi‑Fi — Network-адрес из терминала

Данные хранятся в IndexedDB браузера. На iPhone удобнее открывать с ярлыка «На экран Домой».

## Что умеет сейчас

- Дерево: Дом / Дача / Работа → помещения → шкафы / полки / коробки
- Код места = полный путь (`Дача / Каменный гараж / …`)
- Вещи: постоянные и расходные (шт / кг / уп)
- QR места, сканер и ручной ввод пути
- Печать меток на A4
- Поиск, светлая / тёмная тема
